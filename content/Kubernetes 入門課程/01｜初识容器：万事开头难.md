# 初識容器：Docker 環境搭建入門

## 課程概述
本課程介紹容器技術的起源與 Docker 的發展歷程，並實際示範如何在 Linux 環境中安裝 Docker Engine，透過基本命令操作容器，破除對容器技術的陌生感。

## 核心觀念與實作解析

### Docker 的誕生與發展
- **Docker 於 2013 年 PyCon 大會首度亮相**，創始人 Solomon Hykes 以 5 分鐘的「閃電演講」展示了容器、鏡像、隔離進程等概念
- 這次演示成為雲原生技術浪潮的開端，吸引了 Amazon、Google、Red Hat 等大公司投入
- 最終促成 Kubernetes 的誕生，成為容器管理的主流技術

### Docker 的形態選擇
Docker 有兩種主要產品形態：
- **Docker Desktop**：針對個人使用，支援 Mac/Windows，具備圖形介面與周邊工具整合
- **Docker Engine**：免費、純 Linux 環境、僅支援命令行操作，是生產環境實際使用的版本

**課程推薦使用 Docker Engine**，原因：
1. 為 Docker 原始形態，與 Kubernetes 學習方向一致
2. 完全免費，無商業授權限制問題

### Docker Engine 安裝步驟
在 Ubuntu 系統中使用 apt 安裝：

```bash
sudo apt install -y docker.io          # 安裝 Docker Engine
sudo service docker start              #啟動 Docker 服務
sudo usermod -aG docker ${USER}        # 將當前用戶加入 docker 群組
```

安裝後需 `exit` 退出並重新登入，使群組設定生效。

### Docker 基本命令驗證
- `docker version`：查看客戶端與伺服器版本資訊
- `docker info`：顯示系統資訊（CPU、記憶體、容器數量、儲存檔案系統等）

### Docker 核心操作命令
| 命令 | 功能 |
|------|------|
| `docker ps` | 列出運行中的容器 |
| `docker pull` |從遠端鏡像倉庫拉取鏡像 |
| `docker images` | 列出本地儲存的鏡像 |
| `docker run` |從鏡像啟動容器 |

### Docker Engine 架架
Docker採用 **Client/Server（C/S）架構**：
- **Docker client**：命令行工具，接收用戶指令
- **Docker daemon**：後台服務，實際管理容器與鏡像
- **Registry**：遠端鏡像倉庫，存放鏡像檔案

client 透過 build、pull、run 等命令向 daemon發送請求，daemon負責拉取鏡像、生成容器等實際工作。

## 重點摘要
- 容器技術起源於 Docker，推薦使用免費的 Docker Engine進行學習
- Docker Engine採用命令行操作，主命令為 `docker`，後接各種子命令
- 核心命令包括 `docker version`、`docker info`、`docker ps`、`docker pull`、`docker images`、`docker run`
- Docker 採用 Client/Server 架構，命令行工具為前端，daemon為後端服務核心
