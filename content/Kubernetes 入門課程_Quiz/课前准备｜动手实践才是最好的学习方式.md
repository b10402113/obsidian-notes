## 第一部分：選擇題 (每題 5 分，共 50 分)

**Q1.** 為什麼作者建議在本地搭建 Kubernetes 實驗環境，而不是使用雲主機？

A) 雲主機配置太低，無法運行 Kubernetes
B) 雲主機需要付費、受網路限制、無法完全自主控制，且不利於從零搭建學習
C) 雲主機不支援 Linux 系統
D) 作者不信任任何雲服務提供商

<details>
<summary>答案</summary>
<b>B)</b> 雲主機存在以下問題：需要付費且好配置需更多費用；受網路和廠商限制存在不穩定因素；軟硬體固定無法隨意定制；很難真正「從零搭建」學習。本地虛擬機環境完全自主可控，更適合學習。
</details>

**Q2.** 對於 Kubernetes 學習環境的硬體配置，作者建議宿主機至少應該具備什麼樣的配置？

A) 2 核 CPU、4G 記憶體、100G 硬碟
B) 4 核 CPU、8G 記憶體、300G 硬碟
C) 8 核 CPU、16G 記憶體、500G 硬碟
D) 1 核 CPU、2G 記憶體、50G 硬碟

<details>
<summary>答案</summary>
<b>B)</b> 作者建議宿主機配置：CPU 和硬碟要求不高，4 核、300G 即可，關鍵是記憶體要足夠大，因為虛擬機和 Kubernetes 都很消耗記憶體，最少要有 8G，這樣能支持開兩個虛擬機組成最小集群。
</details>

**Q3.** 對於 Apple M1 晶片的 Mac 電腦，為什麼不能選擇 VirtualBox 作為虛擬機軟體？

A) VirtualBox 在 M1 上運行速度太慢
B) VirtualBox 只能在 Intel (x86_64) 晶片上運行，不支援 ARM64 架構的 M1 晶片
C) VirtualBox 是付費軟體，M1 版本需要額外購買授權
D) Oracle 沒有發布支援 macOS 的 VirtualBox 版本

<details>
<summary>答案</summary>
<b>B)</b> VirtualBox 是 Oracle 推出的虛擬機軟體，雖然支援 Windows 和 macOS，但只能運行在 Intel (x86_64) 晶片上，不支援 Apple 新出的 M1 (arm64/aarch64) 晶片，導致無法在新款 Mac 上使用。
</details>

**Q4.** 在 VirtualBox 中配置網路時，為什麼需要設置兩個網卡？

A) 一個用於上網，一個用於內部通訊
B) "Host-only" 網卡用於本地終端登錄和聯網，"NAT" 網卡用於連接外網
C) 一個網卡無法滿足 Kubernetes 的網路需求
D) 兩個網卡可以提高網路速度

<details>
<summary>答案</summary>
<b>B)</b> 在 VirtualBox 配置中，"網卡 1" 設置為 "Host-only" 網路，用於本地終端登錄和聯網；"網卡 2" 設置為 "網路地址轉換（NAT）"，用於連接外網。這樣可以實現內外網分離，更方便實驗操作。
</details>

**Q5.** 對於 VMWare Fusion 用戶，作者提到有一個 Ubuntu 22.04 的問題需要特別注意，這個問題是什麼？

A) Ubuntu 22.04 無法在 VMWare Fusion 中安裝
B) Ubuntu 22.04 內核從 5.13 升級到 5.15 時引入 Bug，導致無法正常安裝啟動
C) Ubuntu 22.04 不支援 ARM64 架構
D) VMWare Fusion 不支援 Ubuntu 作業系統

<details>
<summary>答案</summary>
<b>B)</b> Ubuntu 22.04 在內核由 5.13 升級到 5.15 時引入了一個小 Bug，導致 VMWare Fusion 無法正常安裝啟動。作者提供了一個較早的 "daily build" 版本可以正常安裝使用，並上傳到雲盤供下載。
</details>

**Q6.** 安裝 Ubuntu 時，作者建議選擇「最小安裝」並在安裝過程中物理斷網，主要原因不包括：

A) 節約安裝時間
B) 避免下載升級包
C) 對 Apple M1 用戶特別重要，防止自動更新到 5.15 內核
D) 節省磁碟空間

<details>
<summary>答案</summary>
<b>D)</b> 選擇最小安裝和斷網的主要原因是節約時間和避免下載升級包。對 Apple M1 用戶來說，斷網特別重要，否則 Ubuntu 會自動更新到 5.15 內核，導致安裝後無法正常啟動。節省磁碟空間不是主要考慮因素。
</details>

**Q7.** 在安裝完 Linux 系統後，為了方便後續實驗，需要安裝 openssh-server 的主要目的是什麼？

A) 提高系統安全性
B) 支持遠程登錄，可以在宿主機上使用 ssh 命令操作虛擬機
C) 加快網路傳輸速度
D) 自動配置防火牆規則

<details>
<summary>答案</summary>
<b>B)</b> Ubuntu 桌面版默認不支持遠程登錄，安裝 openssh-server 後，可以在宿主機上使用 ssh 命令登錄虛擬機，這樣操作更方便，特別適合後續的 Kubernetes 學習實驗。
</details>

**Q8.** 作者建議在配置好虛擬機環境後拍快照，這樣做的主要好處是：

A) 提高虛擬機運行速度
B) 減少記憶體佔用
C) 環境出現問題時可以快速回滾到正確狀態，避免重複安裝系統浪費時間
D) 自動備份重要文件

<details>
<summary>答案</summary>
<b>C)</b> 拍快照是為了做好備份工作，萬一後面有意外發生、環境被弄亂了，可以輕鬆回滾到拍快照時的正確狀態，避免重新安裝系統浪費時間。
</details>

**Q9.** Kubernetes 可以運行在 Windows、macOS 和 Linux 等多種作業系統上，不限於 Linux。 _(對/錯)_

<details>
<summary>答案</summary>
<b>錯</b> - Kubernetes 只能運行在 Linux 之上，這是為什麼需要安裝 Linux 虛擬機的原因。雖然有 Docker Desktop 等工具，但底層仍需要 Linux 環境支援。
</details>

**Q10.** 使用虛擬機搭建實驗環境的好處之一是可以對比虛擬機和容器技術的異同，加深對 Kubernetes 的理解。 _(對/錯)_

<details>
<summary>答案</summary>
<b>對</b> - 虛擬機軟體已經非常成熟可靠，而且很多雲服務商內部也在大量使用虛擬伺服器，Kubernetes 裡的容器技術與虛擬機有很多相似之處，通過使用虛擬機可以對比這些技術的異同點。
</details>

**Q11.** VirtualBox 是付費軟體，且使用條款有很多限制。 _(對/錯)_

<details>
<summary>答案</summary>
<b>錯</b> - VirtualBox 是 Oracle 推出的虛擬機軟體，歷史悠久，一直堅持免費政策，使用條款上也沒有什麼限制，是一個難得的精品軟體。
</details>

**Q12.** 在安裝 Ubuntu 時，下載的 Ubuntu 22.04 鏡像文件後綴名如果是 .mov，可以直接使用，不需要修改。 _(對/錯)_

<details>
<summary>答案</summary>
<b>錯</b> - 由於網站的限制，文件的後綴名可能被改成了 .mov，必須去掉這個後綴，還原成原始的 .iso 才能使用。
</details>

**Q13.** Kubernetes 有完善的圖形化 Dashboard，因此學習過程中不需要使用命令行操作。 _(對/錯)_

<details>
<summary>答案</summary>
<b>錯</b> - 雖然 Kubernetes 有圖形化的 Dashboard，但更多的時候都是在命令行裡工作，因此需要對基本的 Linux 操作有所了解，這是學習 Kubernetes 的必備技能。

## 第四部分：簡答題 (共 15 分)

**Q19.** (5 分) 為什麼作者認為在本地使用虛擬機搭建 Kubernetes 實驗環境比使用雲主機更好？請列出至少三個理由。

<details>
<summary>答案</summary>
<b>參考答案：</b>

作者認為本地虛擬機環境更好的三個主要理由：

1. **成本效益高**：雲主機很少是免費的，都需要花錢，而且想要好配置還要花更多的錢，對於學習來說性價比不高
2. **自主可控**：雲主機在雲上，免不了會受網路和廠商的限制，存在不穩定因素；本地環境不會受制於人，完全自主可控
3. **便於從零學習**：雲主機的軟硬體都是固定的，不能隨意定制，特別是很難真正「從零搭建」，而虛擬機可以完全按照學習需求配置

其他合理理由：
- 虛擬機創建刪除都簡單，成本極低
- 可以通過虛擬機對比容器技術異同，加深理解
</details>

**Q20.** (5 分) 在 VirtualBox 中配置虛擬機網路時，為什麼需要創建 "Host-only" 網路？它和 NAT 網路有什麼區別？

<details>
<summary>答案</summary>
<b>參考答案：</b>

**Host-only 網路的作用：**
- 創建一個僅主機網路，讓宿主機可以和虛擬機直接通訊
- 用於本地終端登錄虛擬機（通過 ssh）
- 提供穩定的區域網路環境，方便實驗操作

**與 NAT 網路的區別：**
- **Host-only**：僅用於宿主機和虛擬機之間的通訊，無法直接訪問外網
- **NAT**：通過網路地址轉換，讓虛擬機可以連接外網，但外部無法直接訪問虛擬機

**配置方案：**
需要兩個網卡配合使用：網卡 1 使用 Host-only 用於本地登錄，網卡 2 使用 NAT 用於連接外網，實現內外網分離。
</details>

**Q21.** (5 分) 簡述在虛擬機中安裝 Ubuntu 22.04 後，需要進行哪些初始化操作才能方便後續的 Kubernetes 學習？

<details>
<summary>答案</summary>
<b>參考答案：</b>

安裝 Ubuntu 22.04 後需要進行以下初始化操作：

1. **安裝常用工具**：
   - 使用 `sudo apt update` 更新軟體包列表
   - 使用 `sudo apt install -y git vim curl jq` 安裝 git、vim、curl、jq 等常用工具

2. **啟用遠程登錄**：
   - 安裝 openssh-server：`sudo apt install -y openssh-server`
   - 使用 `ip addr` 查看虛擬機 IP 地址
   - 在宿主機上使用 ssh 命令登錄虛擬機

3. **配置靜態 IP（可選）**：
   - 在系統設置中將網卡從動態地址（DHCP）改成靜態地址（Manual）
   - 設置合適的 IP、子網掩碼、網關和 DNS

4. **創建快照備份**：
   - 給虛擬機拍快照，做好備份
   - 環境出現問題時可以快速回滾
</details>

## 第五部分：配對題 (共 10 分)

**Q22.** 請將下列 Linux 命令與其功能進行配對：

| 命令 | 功能 |
| ---- | ---- |
| 1. sudo | A. 查看文件內容，支持分頁顯示 |
| 2. ps | B. 發送 HTTP 請求，用於測試伺服器 |
| 3. cat | C. 以臨時 root 權限執行命令 |
| 4. curl | D. 查看系統當前進程列表 |
| 5. vim | E. Linux 流行編輯器，功能強大但學習成本較高 |

<details>
<summary>答案</summary>
<b>1-C, 2-D, 3-A, 4-B, 5-E</b>

<b>解析：</b>
- **sudo**：用於臨時獲取 root 權限執行命令，避免直接使用 root 用戶帶來的安全隱患
- **ps**：Linux 最常用命令之一，用於查看系統當前進程列表
- **cat**：查看文件內容，如果內容太多可以用管道符 `|` 後跟 `more`、`less` 進行分頁顯示
- **curl**：命令行 HTTP 客戶端，常用於測試 HTTP 伺服器（如 Nginx）
- **vim**：Linux 最流行的編輯器，使用方式與一般編輯器不同，學習成本略高
</details>
