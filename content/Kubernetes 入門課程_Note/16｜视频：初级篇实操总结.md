# 初級篇實操總結

## 📝課程概述
本課程是初级篇的视频实操总结，演示 minikube 环境启动、kubectl 操作API 对象、Pod/Job/CronJob/ConfigMap/Secret 的完整操作流程。

## 核心觀念與實作解析

### minikube 环境操作

**查看版本和状态**：
```bash
minikube version
minikube status
minikube node list      # 查看节点列表（IP: 192.168.49.2）
```

**启动集群**：
```bash
minikube start --kubernetes-version=v1.23.3
```

**登录节点**：
```bash
minikube ssh
uname -a                # Ubuntu操作系统
docker version          # 复用宿主机 Docker
docker ps               # 查看 Kubernetes进程容器
```

### kubectl 操作 API对象

**查看版本和 Pod**：
```bash
kubectl version
kubectl get pod
kubectl get pod -n kube-system    # 查看核心组件
```

**查看 API 对象信息**：
```bash
kubectl api-resources             # 所有对象列表
kubectl explain pod               # 字段说明文档
kubectl explain pod.spec.containers
```

**生成 YAML样板**：
```bash
export out="--dry-run=client -o yaml"
kubectl run ngx --image=nginx:alpine $out > pod.yml
```

### Pod 对象操作

**创建和查看**：
```bash
kubectl apply -f ngx-pod.yml
kubectl get pod
kubectl logs ngx-pod
```

**进入 Pod**：
```bash
kubectl exec -it ngx-pod -- sh    # 注意要有 --
nginx -v
uname -a
```

**删除**：
```bash
kubectl delete -f ngx-pod.yml
```

### 离线业务对象操作

**Job 操作**：
```bash
kubectl create job echo-job --image=busybox $out
kubectl apply -f job.yml
kubectl get job
kubectl get pod
kubectl logs echo-job-xxxxx
```

**CronJob 操作**：
```bash
kubectl create cj echo-cj --image=busybox --schedule="" $out
kubectl apply -f cronjob.yml
kubectl get cj
kubectl get pod
```

### 配置信息对象操作

**创建 ConfigMap**：
```bash
kubectl create cm info --from-literal=k=v $out
kubectl apply -f cm.yml
kubectl get cm
kubectl describe cm info
```

**创建 Secret**：
```bash
kubectl create secret generic user --from-literal=name=root $out
echo -n "123456" | base64          # 编码
echo "MTIzNDU2" | base64 -d        # 解码
kubectl apply -f secret.yml
kubectl describe secret user
```

**Volume 方式注入 Pod**：
```yaml
spec:
  volumes:
  - name: cm-vol
    configMap:
      name: info
  containers:
  - volumeMounts:
    - mountPath: /tmp/cm-items
      name: cm-vol
```

```bash
kubectl exec -it vol-pod -- sh
cd /tmp
ls              # 加载成目录
cat greeting    # 文件名就是Key
```

### 在 Kubernetes 搭建 WordPress

**MariaDB**：
```bash
kubectl apply -f mariadb-pod.yml
kubectl get pod -o wide            # 查看 IP 地址
```

**WordPress**：
```bash
kubectl apply -f wp-pod.yml        # HOST 改成 MariaDB IP
kubectl get pod -o wide
```

**端口转发**：
```bash
kubectl port-forward wp-pod 8080:80 &
```

**Nginx 代理**：
```bash
./wp_proxy.sh
docker ps
```

浏览器访问虚拟机 IP 即可看到 WordPress 安装界面。

## 💡 重點摘要
- minikube 是本地学习环境，启动后可用ssh 登录节点
- kubectl api-resources/explain 是编写 YAML 的必备参考
- `--dry-run=client -o yaml` 生成样板，简化 YAML 编写
- kubectl exec 需要 `--` 分隔kubectl 命令和 Shell 命令
- ConfigMap/Secret 通过 Volume 加载后变成目录和文件
