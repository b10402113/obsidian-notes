# Docker入門篇实操总结

## 課程概述
本課程為入門篇的视频实操總結，以實際操作演示 Docker 的核心功能，包括安裝驗證、鏡像容器操作、Dockerfile构建、容器互通、以及 WordPress 部署等完整流程。

## 核心觀念與實作解析

### 一、熟悉 Docker Engine 使用

#### 安裝驗證命令
```bash
docker version                                  # 查看版本（Client/Server）
docker info                                     # 系統資訊（overlay2、CPU、記憶體等）
docker ps                                       #查看運行中的容器
```

#### 基本操作流程
```bash
docker pull busybox                             #拉取鏡像
docker images                                   # 查看鏡像列表
docker run busybox echo hello world             # 啟動容器執行命令
docker ps -a                                    #查看所有容器（含已結束）
docker rm <container_id>                        # 删除容器
```

### 二、鏡像與容器實操

####進入容器内部
```bash
docker pull alpine
docker run -it alpine sh                        # -it 開啟交互式 Shell
cat /etc/os-release                             # 查看容器内系統（Alpine Linux）
exit                                            # 退出容器
```

#### 容器本质验证
```bash
docker run -d --rm nginx:alpine                 #後台運行 Nginx
ps -ef|grep nginx                               # 宿主機可看到容器進程
docker stop <container_id>                      #停止後進程消失
```

**结论**：容器就是被 namespace、cgroup、chroot 限制的普通進程。

### 三、构建自己的鏡像

#### Dockerfile範例
```dockerfile
ARG IMAGE_BASE="nginx"
ARG IMAGE_TAG="1.21-alpine"

FROM ${IMAGE_BASE}:${IMAGE_TAG}

ENV PATH=$PATH:/tmp
ENV DEBUG=OFF

COPY ./default.conf /etc/nginx/conf.d/

RUN cd /usr/share/nginx/html && echo "hello nginx" > a.txt

EXPOSE 8081 8082 8083
```

#### 构建與验证
```bash
docker build -t ngx-app:1.0 .                   # 构建鏡像
docker run -it --rm ngx-app:1.0 sh              #進入容器验证
docker save ngx-app:1.0 -o ngx.tar              #導出鏡像
docker load -i ngx.tar                          # 從壓縮包恢復
```

### 四、容器與外界互通

#### docker cp 文件拷貝
```bash
docker run -d --rm redis
echo 'aaa' > a.txt
docker cp a.txt 062:/tmp                        # 拷進容器
docker exec -it 062 sh                          # 进入验证
docker cp 062:/tmp/a.txt ./b.txt                #拷出容器
```

#### -v 目录共享
```bash
docker run -d --rm -v /tmp:/tmp redis           #挂載目录
docker exec -it b5a sh                          #容器内目录與宿主機同步
```

#### -p 端口映射
```bash
docker run -d -p 80:80 --rm nginx:alpine        # 映射端口
docker ps                                       #查看端口映射狀態
curl 127.1:80 -I                                #验证服務可访问
docker exec xxx ip addr                         #查看容器网卡（172.17.0.2）
```

### 五、WordPress 搭建流程

脚本化部署三容器：
1. **MariaDB**：設置环境變數（数据庫、用户、密码）
2. **WordPress**：连接 MariaDB（需指定 DB_HOST IP）
3. **Nginx**：反向代理配置文件以 `-v` 挂載

```bash
# 执行脚本後
docker ps                                       # 确认三容器運行
# 瀏覽器访问 IP 地址進入 WordPress
```

## 重點摘要
- `docker version`、`docker info`驗證安装與系統狀態
- `-it`参数進入容器交互，`-d` 后台運行
- Dockerfile构建鏡像：`FROM`、`COPY`、`RUN`、`ENV`、`EXPOSE`
- `docker cp`拷文件，`-v` 共享目录，`-p` 映射端口
- WordPress 部署需 MariaDB → WordPress → Nginx 三容器協作

## 關鍵字
docker version, docker build, docker cp, -v, -p
